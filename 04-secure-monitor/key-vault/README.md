## What it is

A managed vault for **secrets, keys, and certificates** so credentials never live in your
code or config files. Apps read secrets at runtime using their Azure identity (**managed
identity**), and secrets can be **rotated** without redeploying.

## Why it's on the exam

Storing and **retrieving** secrets from code (with managed identity, not connection strings),
and **rotation**. Often paired with App Configuration references.

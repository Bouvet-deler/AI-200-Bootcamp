## What it is

A central store for **application settings** and **feature flags**, so all your services read
the same config from one place instead of scattered files. It can **reference Key Vault** for
the secret values (config here, secrets there).

## Why it's on the exam

Reading/writing configuration keys, labels for per-environment values, feature flags, and
Key Vault references.

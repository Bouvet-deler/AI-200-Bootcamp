## What it is

A vendor-neutral standard + SDK for **telemetry**: **traces** (a request's journey across
services, made of **spans**), metrics, and logs. In Azure you export this data to
**Application Insights / Azure Monitor**, then query it with [KQL](../kql/).

## Why it's on the exam

Instrumenting a Python app with the OpenTelemetry SDK + Azure Monitor exporter, understanding
traces/spans, and correlating telemetry across services.

## What it is

**AKS** is Azure's *managed* Kubernetes — you get a cluster to run containers at scale, and
you describe what to run with **manifest files** (YAML for Deployments, Services, etc.).

## Why it's on the exam

Applying manifests (`kubectl apply`), and troubleshooting: reading pod logs, inspecting
events, and checking end-to-end connectivity between services.

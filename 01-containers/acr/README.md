## What it is

A **private registry** for your container images (like Docker Hub, but yours and inside
Azure). **ACR Tasks** can build images in the cloud so you don't need Docker locally.

## Why it's on the exam

Building, tagging/versioning, and pushing images; using ACR Tasks (`az acr build`) to build
on-demand or on a trigger; authenticating other Azure services to pull from ACR.

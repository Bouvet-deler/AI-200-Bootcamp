## What it is

**App Service** is Azure's managed web-app hosting (PaaS). It can run your app *from a
container image* instead of raw code, while Azure handles the servers, scaling, and TLS.

## Why it's on the exam

Deploying a container image to App Service; injecting **app settings** (environment
variables) and **secrets** (e.g. Key Vault references) into the running container.

## What it is

**Serverless** functions: small pieces of code that run **on a trigger** and scale
automatically — you don't manage servers. A **trigger** starts the function (HTTP request,
queue message, timer…); **bindings** wire inputs/outputs (e.g. read from Cosmos DB, write to
a queue) without boilerplate.

## Why it's on the exam

Writing HTTP/queue/timer-triggered functions with input/output bindings, and configuring +
deploying the **function app**.

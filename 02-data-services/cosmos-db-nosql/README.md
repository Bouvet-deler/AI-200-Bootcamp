## What it is

A globally distributed **NoSQL** database. Data lives in **containers** as JSON **items**,
partitioned by a **partition key**. Throughput is billed in **Request Units (RUs)**. It can
also store **vector embeddings** and do similarity search for AI retrieval.

## Why it's on the exam

SDK connect + query; tuning cost/latency via **indexing policies** and **consistency
levels**; **vector search** for semantic retrieval; the **change feed** to react to inserts
and updates.

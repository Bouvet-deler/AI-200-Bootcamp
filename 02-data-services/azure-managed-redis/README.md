## What it is

An **in-memory** data store (very fast key/value). Used to **cache** expensive results (e.g.
LLM responses) with **expiration (TTL)** and **invalidation**, and — with the vector module —
to do **similarity search** on embeddings.

## Why it's on the exam

Cache read/write, setting TTLs, invalidating stale entries, and building a vector index for
similarity search.

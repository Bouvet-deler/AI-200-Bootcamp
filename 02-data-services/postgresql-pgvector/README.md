## What it is

Managed **PostgreSQL** (a relational SQL database) in Azure. The **`pgvector`** extension adds
a `vector` column type + similarity indexes, so the same database that holds your relational
data can also power **RAG** (retrieval-augmented generation) with metadata filtering.

## Why it's on the exam

SDK connect/query; schema + indexing design; sizing compute for vector work; storing
embeddings and running similarity search for RAG; connection pooling to cut latency.
